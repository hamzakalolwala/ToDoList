# e-Muhaffiz — credits

- **Tajweed model**: HisnLabs Tajweed v2 (Apache-2.0), https://huggingface.co/Hisnlabs/tajweed-v2 — downloaded by the
  browser from Hugging Face on first use. The judging logic in `engine.js` follows the description of its rule engine
  (imam.py, https://github.com/HisnLabs/tajweed, Apache-2.0), rewritten in JavaScript.
- **Phonetic script and tajweed tags** in `data/`: generated with quran-transcript (MIT), https://github.com/obadx/quran-transcript
- **Model runtime**: onnxruntime-web (MIT).
- **Display text**: quran-json (CC-BY-SA 4.0, Tanzil text), https://github.com/risan/quran-json
- **Fonts**: Amiri Quran and Inter (SIL Open Font License), via Fontsource.
